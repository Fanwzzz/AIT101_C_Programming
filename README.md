# AIT101_C_Programming

Personal C programming exercises for **AIT101 Programming Language C 2026/09**.

The `tutorial/` directory contains my practice code for the course tutorials. Each `.c` file is a separate exercise; most can be compiled and run on their own. For example, on macOS or Linux:

```sh
mkdir -p build
cc -std=c17 tutorial/tutorial1/ex1.c -o build/ex1
./build/ex1
```

This repository contains personal exercise code, not official course materials. Lecture slides and tutorial handouts are kept locally and are not part of the repository. The MIT license applies to the code in this repository; it does not grant rights to third-party course materials.
